# SegmentedControl

- Caption in `label` (`muted`). Track `wash`, 3px inset, `radius-pill`.
- Options in `ui` `ink-2`; hover `paper`; active `forest` + `paper`. The Dramione option's active fill is `dramione`.
- Put thresholds in the label: "Long (>300 pg)".
