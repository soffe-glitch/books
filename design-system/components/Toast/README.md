# Toast

A short confirmation that slides up in the bottom-right corner after a save.

## Use
- Fixed 2rem from bottom and right; `accent` ground, `white` text, 1rem 1.5rem, `radius-md`, `shadow-menu`, `z-modal`; slides up 100px with a 0.3s fade.
- Past-tense statement of what happened: "Saved", "Marked as read". No buttons.

Source classes: `.toast`.
