# PickCard

The random TBR pick: the one inverse, forest card in the product.

## Use
- `forest` ground, `radius-lg`, `shadow-lift`, max 560px. Appears with a 0.4s rise (`.tbr-pick-animate`).
- Title in `section-title` `paper`; author italic in `mint-on-forest`; meta in `sage-on-forest`.
- Actions: Start Reading (`mint` pill, `forest` label) and Pick another (white ghost).
- Only ever one on screen. Don't use the inverse treatment for anything else, so the pick stays special.
