# DramioneCorner

The pink-accented panel for Dramione fanfiction stats: small figure cells and highlight callouts.

## Use
- Panel gets `.dramione-panel` (4px `badge-pink` top rule).
- Cells: `dramione-tint` ground, `radius-lg`, value Playfair 1.5rem `primary`, label 0.7rem uppercase `gray-500`.
- Callouts `.dramione-highlight`: `dramione-tint-strong` ground, 3px `badge-pink` left rule, 0.85rem `gray-700`, the title in `gray-900` 600. Pattern: "Top pick: **Title** — ★ 5 · Author".
- Pink is reserved for Dramione. Don't use it for other genres.

Source classes: `.dramione-*`.
