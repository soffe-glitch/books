# DramioneCorner

The Dramione stats panel, marked by a `dramione` dot before its heading.

- Cells on `dramione-wash` (`radius-md`); figures in Newsreader `dramione`, captions in `label`.
- Highlights are hairline-separated lines: "Top pick: **Title** — ★ 5 · Author", the title in Newsreader.
- Pink means Dramione. Don't use it anywhere else.
