# RankedList

A top-five list with a large faded rank, a name with meta, and the measured figure on the right.

## Use
- Row: rank in Playfair 1.6rem `gray-300` (32px column), name in `item-name` `gray-900`, meta 0.75rem `gray-500` ("N books · N words"), figure in Playfair 1.4rem `primary`.
- 1px `gray-100` dividers, none after the last row.
- Hours read as "12h 30m"; from 100 hours, whole hours only ("658h").

Source classes: `.universe-*`.
