# Badge

Small pills that name a platform, an ownership type or a genre tag.

| Value | Class | Tokens |
|---|---|---|
| Kindle | `.badge-kindle` | `badge-kindle` on `badge-kindle-bg` |
| Physical, Borrowed | `.badge-physical`, `.badge-borrowed` | `badge-physical` |
| Mofibo | `.badge-mofibo` | `badge-mofibo` |
| AO3 | `.badge-ao3` | `dramione` on `dramione-wash` |
| Apple Books, unknown, Free | `.badge-apple` … | `badge-neutral` |
| Saxo | `.badge-saxo` | `badge-saxo` |
| Audiobook, Streamed | `.badge-audiobook`, `.badge-streamed` | `badge-indigo` |
| Owned | `.badge-owned` | `forest` on `mint` |
| Genre tag | `.badge-tag` | `forest` on `wash` |

All text colours reach at least 5:1 on their grounds. A missing value is a `faint` em dash, never an empty badge.
