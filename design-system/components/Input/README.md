# Input

Form fields for adding and editing books.

- Label above in `label` (`muted`, uppercase). Fields: `paper`, 1px `line-strong`, `radius-md`, 0.6rem 0.8rem, `body` at 0.95rem; hover `control`; focus `emerald-ink` border + 3px `mint` halo.
- `.form-row` auto-fits columns of at least 150px, so rows reflow on phones.
- Platforms are `.platform-checks`: pill checkboxes that turn `mint` with an `emerald-ink` border when checked.
